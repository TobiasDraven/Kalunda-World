# Placeholders — images and audio

Empty on purpose. Drop files here and point the HTML at them.

**Prompt files:** `10-WORLD/IMAGE-PROMPTS-CHARACTERS.md` (40 prompts) and `10-WORLD/IMAGE-PROMPTS-PLACES.md` (19 prompts). Every prompt has an ID below, so a rendered file can be dropped in against a known name instead of being renamed by hand afterwards.

**Method and style:** `10-WORLD/VISUAL-BIBLE.md` is the lock — register, palette, light by hour, materials, dress. `10-WORLD/_REVIEW/IMAGE-PROMPT-RESEARCH.md` is the method. Prompts are model-agnostic: paste, adapt, render.

## ID scheme

`CH-<FIGURE>-<NN>` for characters, `PL-<PLACE>-<NN>` for places, `AR-<STRUCTURE>-<NN>` for recurring architecture. The number is the prompt's order inside its section in the prompt file, so a mismatch means the prompt file has been edited and this map needs re-deriving.

## assets/audio/
Suggested files (mono, 64–96 kbps MP3, under ~1 MB each):

| File | Used by | Content |

| `kbs-bulletin-140106.mp3` | radio page | 06:00 bulletin — the day's official line |
| `kbs-bulletin-140112.mp3` | radio page | 12:00 bulletin — the day's official line, updated |
| `kbs-interview-XXXX.mp3` | radio page | Optional interview clip — a resident, a trader, an official |

Scripts are written as 10 sentences maximum and read by the operator's chosen text-to-speech service. Keep the in-world fiction: the station sounds slightly under-resourced, not polished.

## Dimensions

Character prompts: 4:5 at 1024 × 1280. Place prompts: 3:2 at 1500 × 1000, or 16:9 at 1600 × 900. Keep files under ~300 KB — JPEG quality 80 is enough for a projected page and a printed handout.

## Label rule
Everything on this site is simulated media produced for a fictional setting. Keep the `README.md` claim ("fictional") in the repo, and never present generated imagery as a real photograph.
